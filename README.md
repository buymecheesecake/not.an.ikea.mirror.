## ۝ What is this?
not.an.ikea.mirror flips every webpage horizontally, turning your browser into a digital mirror.

Whether you're checking your posture in the browser window or just want to feel like you're browsing in a parallel universe, this extension is here for your useless, delightful needs.

## ۝ Features  
1. Flips all page content horizontally — text, images, buttons, you name it

2. install and activate

3. Pairs great with existential crises and self-reflection  

## ⚙️ Installation  
1. Clone or download this repo

2. Go to chrome://extensions/ in your Chrome browser

3. Enable Developer Mode (top-right)

4. Click "Load unpacked" and select the folder  

5. Boom. You’re now seeing the world backwards.

## ✘⚙️ Uninstallation
just disable it
